# 历史验证记录与可复用范围

以下是 2026-10-20 整理的一个 ENVI 5.6 / IDL 8.8 Windows 64 位环境的经验，属于历史事实，不能当作其他机器或未来会话的实时状态。

| 环节 | 已有证据 | 尚不代表 |
|---|---|---|
| Classic MCP | 协议握手、12 个工具、启动自己的诊断会话、读取菜单、正常关闭；整理时健康检查通过 | 全部菜单或正式实验已完成 |
| Task Engine MCP | 协议握手、37 个工具、实际列出 240 个任务；整理时再次检查通过 | 240 项计算均通过验收 |
| 小型真实计算 | 8×8 float32 合成栅格执行 `b1 * 2.0`，64 像元正确，CRS 和 transform 保持 | 所有算法、比例因子和 NoData 语义已验证 |
| SDK 兼容 | 本地修复 `execute(parameters)` 参数传递及 `outputParameters` 提取 | 上游原版已包含相同修复 |
| SAR/InSAR | 目录只发现 `RadarBackscatter` 这一相关任务 | SARScape/InSAR 专用工作链已安装或获许可 |
| 例程研究 | 查询 63 个 SAVE 文件、32,953 条例程记录、14 个接口签名；获得若干原生函数伪代码 | 恢复整个 ENVI 的原始源码 |
| Modeler 研究 | 21 个示例文件；20 个模型的处理任务名可在该环境目录找到 | 20 个模型已实际完整运行 |
| 正式报告流程 | 已具备规则与工具入口 | 已按某份真实指导书完成全套截图和最终报告 |

原生反编译代码、厂商保存文件和个人运行证据不随本技能分发。需要研究结果时在用户授权的本地资料中查找，不把符号名、参数签名当成原始算法实现。

复用时可直接使用调用分流和验收规则；安装路径、环境、许可、具体数据和真实计算结果必须按当前任务重新确认。小型数值回归在更改 SDK、计算实现或出现疑点时进行，不为每次简单查询重复跑全部测试。
